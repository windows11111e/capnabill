Capnabil Mobile - تطبيق أندرويد (APK)
=====================================
يعمل على أندرويد 5.1 فصاعدا (API 22+) وهو يغطي تقريبا كل الهواتف المستخدمة اليوم.

الطريقة الاسهل (بدون Android Studio) - عبر GitHub:
1) انشئ حسابا مجانيا على github.com وانشئ مستودعا جديدا (Repository)
2) ارفع محتويات هذا المجلد كلها (بما فيها المجلد المخفي .github)
3) ادخل تبويب Actions -> Build APK -> Run workflow
4) بعد 5-8 دقائق افتح التشغيلة ونزّل الملف Capnabil-apk ففيه app-debug.apk
5) انقله للهاتف وثبّته (فعّل "السماح بالتثبيت من مصادر غير معروفة")

الطريقة المحلية على ويندوز: ثبّت Node.js و JDK 17 و Android Studio ثم شغّل build-apk.bat

بدون APK: ارفع مجلد www على استضافة https (مثل GitHub Pages) وافتحه في كروم من الهاتف
-> قائمة -> "اضافة الى الشاشة الرئيسية" فيعمل كتطبيق PWA.

ملاحظة: الـ APK الناتج موقّع بمفتاح debug وهو صالح للتثبيت المباشر. للنشر على Google Play تحتاج توقيع release.
